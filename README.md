# ゆきの里ゲームズ

くだらないゲーム置き場です。ブラウザだけで遊べて、スマホでも PC でも動きます（パソコン向けのゲームもあります）。
ほとんどのゲームに 🤖 オートモードがついていて、コンピューターが上手な遊び方を見せてくれます（ダイナマイトマンはオートなしで、コンピュータと対戦します）。

**▶ あそぶ：https://apapane-yukinosato.github.io/games/**

## 🤖 オートモード

- 各ゲームの「🤖 オート」ボタン、またはキーボードの **O キー**でオン／オフ
- タイトル画面でオンにすると、そのままオートで始まる
- オート中に自分で操作すると、手動にもどる
- 1回終わると、自動で次のプレイが始まる

## しくみ

- 1ゲーム＝1フォルダ＝1ファイル（`<ゲーム名>/index.html` に HTML・CSS・JavaScript をまとめて入れています）
- 画像や音声ファイルは使っていません。絵は canvas に描き、音と音楽は Web Audio API でその場で作っています
- 外部ライブラリは `candy/` の three.js（3D表示）だけです
- ハイスコアや設定はブラウザ（localStorage）に保存されます
- `main` ブランチに入ると GitHub Pages に自動で公開されます

## 手元で動かす

```sh
python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開きます。

## ゲームを追加するとき

1. 新しいフォルダを作り、`index.html` にゲームを書く
2. `index.html`（メニュー）の合うカテゴリに `<li>` を1つコピーして、リンクと説明を書きかえる（カテゴリのボタンと見出しの数も1つ増やす）
3. この README の「ゲーム一覧」にも1行足す
4. 🤖 オートモードなど、入れるものは [CLAUDE.md](CLAUDE.md) を見る
